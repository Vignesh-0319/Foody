# Foody

[Watch the app demo on YouTube](https://www.youtube.com/shorts/b4obJeiXv-I)

Native SwiftUI campus meal discovery with a Python and SQLite backend. Students select a university, browse meals within budget, vote on dishes and discuss meals.

## Run locally

Start the API with `python3 server/server.py` (Python 3.9+). Open `Foody.xcodeproj` in Xcode, choose an iPhone simulator and press Command-R. The app connects to `http://127.0.0.1:8787` by default. University listings and starting verdicts are sample data.
